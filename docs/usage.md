# Інструкція з використання (Usage)

## Запуск AI-агента
Для автоматичної генерації структури проєкту, коду та тестів, відкрийте GitHub Copilot Chat і відправте наступний запит:

> @workspace Прочитай файл .github/agents/build-engineer.agent.md, щоб зрозуміти свою роль. Після цього виконай інструкції з файлу prompts/init.prompt.md. Створи всі необхідні файли для C++ проєкту з CMake та GoogleTest.

## Локальна компіляція (Складання)
Для генерації файлів збірки через CMake виконайте в терміналі:
`cmake -S . -B build`

Для безпосередньої компіляції проєкту виконайте:
`cmake --build build`

## Запуск тестів
Для запуску юніт-тестів (з урахуванням мультиконфігураційного середовища на Windows) виконайте:
`ctest --test-dir build -C Debug`
