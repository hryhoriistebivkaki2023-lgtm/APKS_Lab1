# Архітектура AI-агента

* **Які проблеми вирішує агент:** Автоматизує створення базової структури C++ проєкту, налаштування CMake, написання юніт-тестів та створення CI/CD пайплайну для GitHub Actions.
* **Які skills він використовує:** 
  - `project-scaffold` (створення файлів проєкту)
  - `build-and-test` (налаштування CMake та тестів)
  - `github-actions` (налаштування ci.yml)
* **Які commands доступні користувачу:** `git-init`, `create-project`, `create-build`, `create-actions`, `check`, `init`.
* **Які дані передаються між етапами:** Назва проєкту, шляхи до створених C++ файлів, конфігурація CMake передається для налаштування тестів.
* **Як оркестратор обробляє помилки:** Команда `init` запускає кроки послідовно. Якщо перевірка (`check`) виявляє відсутність файлу або помилку компіляції, процес зупиняється з виведенням звіту.
