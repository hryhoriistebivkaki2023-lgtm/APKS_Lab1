# Команда: init (Оркестратор)

Ти — оркестратор. Твоє завдання — послідовно запустити повний сценарій створення проєкту. 
Виконай наступні команди по черзі, очікуючи завершення кожної перед переходом до наступної:
1. Запусти команду `git-init`.
2. Запусти команду `create-project`.
3. Запусти команду `create-build`.
4. Запусти команду `create-actions`.
5. Запусти команду `check`.

Якщо на будь-якому кроці виникає помилка, зупини роботу і повідом мене, що пішло не так.
